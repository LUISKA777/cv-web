# 🛡️ Portafolio Profesional - Luis Carlos Solís Rodríguez

Este proyecto es un Currículum Vitae interactivo diseñado con una estética **Cyberpunk/Tech**, enfocado en resaltar el perfil de un estudiante de Ingeniería en Sistemas con especialización en Ciberseguridad.

## 🚀 Tecnologías Utilizadas

- **HTML5**: Estructura semántica y optimizada para SEO.
- **CSS3**: 
  - **Custom Properties (Variables)**: Para una gestión eficiente de colores y tipografías.
  - **Animaciones Avanzadas**: Uso de `@keyframes` para efectos de carga, flotación y rotación.
  - **Glassmorphism**: Efectos de desenfoque de fondo (`backdrop-filter`) en las tarjetas.
  - **Responsive Design**: Adaptabilidad total a dispositivos móviles mediante Media Queries.
- **JavaScript**: Implementación de efectos dinámicos, interactividad en el terminal y control de animaciones al hacer scroll.
- **Fuentes**: JetBrains Mono (para el look de código) y Space Grotesk (para lectura moderna).

## 🎨 Concepto Visual y Diseño

El diseño fue concebido para transmitir una identidad ligada a la seguridad informática y la programación:

- **Paleta de Colores**: Fondo oscuro profundo (`#070b12`) con acentos en Cian, Violeta y Verde Neón, simulando interfaces de terminales de seguridad.
- **Elementos Clave**:
  - **Hero Section**: Incluye un anillo de carga dinámico que rodea la foto de perfil, simulando un proceso de análisis de sistema.
  - **Terminal Interactiva**: Una sección que emula una consola de comandos de Linux para presentar el perfil personal.
  - **Red Dinámica**: Un fondo animado mediante Canvas que representa la interconexión de nodos en una red.
  - **Efecto de Grano**: Una capa sutil de ruido visual para darle una textura de monitor antiguo.

## 📁 Estructura del Proyecto

```text
cv-web/
├── assets/             # Recursos multimedia (foto de perfil, iconos)
├── index.html          # Estructura principal y contenido
├── style.css           # Estilos globales y animaciones
└── script.js           # Lógica de interactividad y efectos
```

## 🛠️ Instalación y Ejecución

Al ser un proyecto de frontend estático, no requiere instalación de dependencias. 

1. Clona el repositorio:
   ```bash
   git clone https://github.com/LUISKA777/cv-web.git
   ```
2. Abre el archivo `index.html` en cualquier navegador moderno.
